# Registro de Baño

## Objetivo

Registrar rápidamente una evacuación desde móvil.

## Variables

### Fecha y hora

occurred_at

### Escala Bristol

1 a 7.

### Urgencia

0 a 4.

### Dolor

0 a 4.

### Notas

Opcionales.

## Diseño

Las variables estructuradas se seleccionan mediante botones táctiles.

La aplicación evita pedir al usuario escribir datos que pueden clasificarse.

## Razón

Estos valores estructurados serán utilizados posteriormente para calcular
asociaciones con alimentos.

# Calendario

## Objetivo

Permitir consultar el historial digestivo por fecha.

## Vista Hoy

Existe un calendario horizontal de siete días.

Permite cambiar rápidamente el día seleccionado.

## Vista mensual

La pestaña Calendario muestra:

- mes;
- navegación anterior/siguiente;
- selección de día;
- indicadores de eventos;
- timeline del día seleccionado.

## Indicadores

- comida: color de dominio food;
- baño/Bristol: color de dominio bathroom.

## Datos

La fuente es:

public.timeline_events

La consulta respeta Row Level Security.

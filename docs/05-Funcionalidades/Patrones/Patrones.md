# Patrones

## Concepto

La pestaña se llama Patrones y no Estadísticas.

## Objetivo

Traducir los registros del usuario a información comprensible.

## Estado inicial

La primera versión muestra información de los últimos 30 días:

- comidas registradas;
- evacuaciones registradas;
- promedio Bristol;
- número de eventos Bristol 6–7.

## Regla epistemológica

FoodAndSalud no debe presentar correlaciones como causalidad.

Las frases deberán utilizar términos como:

- asociación;
- coincidencia temporal;
- aparece con frecuencia;
- posible patrón.

Evitar:

- causa;
- provoca;
- demuestra.

# Pantalla Hoy — Inspiración Flo

## Objetivo

FoodAndSalud adopta una experiencia mobile-first inspirada en la claridad
visual de Flo, sin copiar su identidad, marca, ilustraciones ni contenido.

## Elementos adoptados

- foco en el día actual;
- calendario horizontal;
- jerarquía visual amplia;
- fondo suave y orgánico;
- acciones rápidas circulares;
- navegación inferior persistente;
- pocos elementos principales por pantalla.

## Adaptación FoodAndSalud

Flo:

- registrar periodo;
- síntomas;
- sexo.

FoodAndSalud:

- registrar comida;
- registrar Bristol;
- medicina.

## Estructura de Hoy

1. marca / perfil / acceso a calendario;
2. fecha;
3. calendario horizontal de siete días;
4. resumen digestivo;
5. acciones rápidas;
6. timeline del día;
7. navegación inferior.

## Regla

No agregar contenido editorial o consejos únicamente para ocupar espacio.

La pantalla debe priorizar:

- registrar;
- consultar;
- comprender.

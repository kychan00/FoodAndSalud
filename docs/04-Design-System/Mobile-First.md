# Mobile First

## Objetivo

Diseñar FoodAndSalud como una aplicación que pueda utilizarse cómodamente
desde un teléfono en cualquier momento del día.

## Anchos

Las pantallas no necesitan aprovechar todo el ancho disponible en escritorio.

El contenido principal debe permanecer limitado y centrado.

## Formularios

Los formularios deben:

- ser verticales;
- usar inputs grandes;
- reducir escritura innecesaria;
- evitar formularios excesivamente largos;
- ofrecer valores frecuentes cuando sea posible;
- permitir guardar rápidamente.

## Touch

Los elementos interactivos deben tener áreas cómodas para tocar.

Botones principales:

- ancho completo cuando tenga sentido;
- altura aproximada de 48 px o superior;
- separación suficiente entre acciones.

## Navegación futura

La navegación principal móvil deberá considerar una barra inferior.

Áreas candidatas:

- Inicio
- Alimentos
- Baño
- Insights
- Perfil

## Registrar

Registrar será una acción prominente.

El usuario deberá poder llegar rápidamente a:

- Registrar alimento
- Registrar baño

## Escritorio

La versión desktop funcionará como una ampliación de la experiencia móvil.

No se diseñará como un dashboard empresarial de gran densidad.

# MOC — Alimentos

## Dominio

Registro estructurado de alimentos y comidas.

## Conceptos

- Food
- Food Entry
- Food Entry Item
- Meal Type
- Quantity
- Unit
- Food Category
- Frequent Food

## Principio

Registrar debe ser rápido, pero los datos deben conservar suficiente
estructura para permitir análisis posteriores.

## Ejemplo conceptual

Una comida puede contener varios alimentos.

Ejemplo:

Tacos al pastor

- tortilla
- carne
- piña
- cebolla
- cilantro
- salsa

La aplicación no deberá obligar al usuario a registrar siempre ese nivel
de detalle para poder guardar rápidamente una comida.

# ADR-0013 — Navegación móvil de tres pestañas

## Decisión

La navegación principal de FoodAndSalud tendrá tres destinos:

1. Hoy
2. Calendario
3. Patrones

## Hoy

Pantalla operativa principal.

Permite:

- consultar el día;
- seleccionar fechas cercanas;
- registrar comida;
- registrar Bristol;
- acceder a Medicina;
- revisar timeline.

## Calendario

Permite:

- navegar por meses;
- identificar días con registros;
- diferenciar visualmente comida y baño;
- consultar el timeline de una fecha.

## Patrones

Reemplaza el término Estadísticas.

Motivo:

Patrones expresa mejor el objetivo del sistema:

descubrir asociaciones personales entre alimentos y comportamiento digestivo.

## Razón para limitar a tres tabs

FoodAndSalud debe permanecer simple.

No se agregarán tabs únicamente porque exista espacio disponible.

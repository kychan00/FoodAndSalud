# FoodAndSalud

FoodAndSalud es una aplicación web personal para registrar alimentación,
evacuaciones y patrones temporales entre ambos tipos de eventos.

El objetivo principal no es diagnosticar enfermedades ni afirmar causalidad,
sino ayudar a descubrir asociaciones repetidas entre alimentos consumidos
y cambios posteriores en el comportamiento gastrointestinal.

## Principios

- Registro rápido.
- Interfaz fácil de leer.
- Mobile first.
- Privacidad por diseño.
- Datos estructurados.
- Estadística interpretable.
- Componentes reutilizables.
- Design System centralizado.
- Documentación desde el inicio.
- Cada bug importante debe producir conocimiento permanente.
- Toda solución reutilizable debe convertirse en patrón documentado.
